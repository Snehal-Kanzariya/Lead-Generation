# 004 — Founder's Command Center

## Requirements
- **FR-060** `GET /api/dashboard` returns metrics computed from persisted data only:
  - `researched` = leads with a successful analysis
  - `qualified` = stage ≥ Qualified (excluding Lost) 
  - `awaiting_review` = drafts in `draft`
  - `outreach_sent` = drafts in `sent`
  - `responses` = logged replies; `positive_reply_rate` = positive / outreach_sent (null if 0 sent)
  - `meetings` = leads that reached Meeting Scheduled or later (ever, via activity)
  - `proposals` = reached Proposal Sent or later
  - `active_deals` = stage in Meeting Scheduled…Negotiation
  - `pipeline_value` = Σ deal_value of open leads at Proposal Sent/Negotiation (estimated)
  - `confirmed_revenue` = Σ deal_value of Won
  - `pending_followups` = open tasks; `overdue_followups`
  - `funnel` = counts per stage; `lead_sources` = counts and won counts per source
- **FR-061** Each metric has a plain-language definition shown in a tooltip/info text.
- **FR-062** Best Opportunity Today = highest opportunity_score among non-Lost, non-Won, not do_not_contact leads with analysis; shows evidence and a next action. Empty state if none.
- **FR-063** Today's Focus is generated by rules from data: overdue/due-today tasks, drafts awaiting review, analyzed-but-undrafted qualified leads, discovered-but-unresearched leads, proposals stalled > 7 days. Empty state if nothing.
- **FR-064** Agent activity panel lists agents with status derived from `agent_runs` (running only if an open run exists), last task, last error, run counts, token usage.
- **FR-065** Zero-data state shows guidance ("Add your first lead"), never fake numbers.

## Acceptance criteria
- **AC-060** Empty workspace → all counts 0, rates null, no focus items except "add first lead".
- **AC-061** Won lead with 1000 → confirmed_revenue 1000 and pipeline_value excludes it.
- **AC-062** Agent shows idle when only finished runs exist; running when an open run exists.
- **AC-063** Stalled proposal (>7d) appears in Today's Focus.
