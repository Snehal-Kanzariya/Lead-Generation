# Constitution

Founder: Snehal Kanzariya · Agency: Shiv Creative Agency. Agency-first, SaaS-second.

## Principles (MUST)

- **C1 Outcome over feature.** Copy and AI output lead with the customer's situation and desired outcome, not our features.
- **C2 Evidence discipline.** Every claim about a prospect is labelled `verified` (has a source URL + date), `hypothesis`, or `unknown`. Emotional concerns are never `verified`.
- **C3 No invention.** No fabricated financial outcomes, testimonials, contact details or case studies. Proof comes only from the founder-supplied portfolio list.
- **C4 No manipulation.** No fake urgency, no fear/shame appeals, no guaranteed results.
- **C5 Human approval.** The system never sends outreach. Drafts require explicit approval; sending is recorded manually by the user.
- **C6 Real data only.** Dashboard figures derive from persisted records. Confirmed revenue (won deals) is separate from estimated pipeline. No seeded demo metrics.
- **C7 Honest agent status.** An agent is shown "running" only while a real run record is open. Failures are logged and shown.
- **C8 Secrets server-side.** API keys never reach the browser or git.
- **C9 Workspace boundary.** Every row carries `workspace_id`; every query filters by it.
- **C10 Simplicity.** Deliver one vertical slice; defer enterprise features (see ROADMAP).
- **C11 Privacy & compliance.** Store only public business information; respect opt-outs (`do_not_contact`); fetch only public pages.
